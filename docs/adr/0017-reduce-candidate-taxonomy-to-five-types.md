# 将 Candidate Taxonomy 精简为五类

格致首版只发布 `method`、`claim`、`limitation`、`relevance` 和 `open_question` 五类 Candidate Knowledge。旧分类中的 Paper Candidate 改为 Work 的处理优先级和阅读价值；Experiment、Metric、Dataset 与 Object 只作为 Reading Result 中的 Study Descriptor，Candidate 只能通过受控 Descriptor Reference 引用同一 Reading Result 中的方法或描述符。Comparison 仍属于 Claim，以规范陈述与 `comparative_claim` Review Risk Flag 表达，不再建立 subtype；每条 Candidate 仍须独立引用 Evidence Block，从而减少重复候选和人工审核负担，同时保留完整阅读信息。
