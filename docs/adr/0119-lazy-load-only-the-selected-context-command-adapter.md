# 只延迟加载已选中的 Context command adapter

本 ADR 是对 [ADR 0111](./0111-lazy-import-the-cli-framework-and-command-graph-after-argv-preflight.md) 与 [ADR 0112](./0112-package-gezhi-with-two-launch-adapters-and-one-bootstrap-seam.md) 的局部 replacing decision：只替换每个 `RawArgvPreflightV1` PASS path 都 eager import 全部 Context command adapters 或调用 `open_gezhi()` composition 的要求。Preflight PASS 后仍必须先完成 `BootstrapPrerequisiteProbeV1` 与 `StaticCommandGraphDescriptorValidatorV1` 两项 typed bootstrap checks；只有 ready/valid verdict 均成立，才加载 Typer/Rich bootstrap runtime closure 与 project-owned inert full routing grammar/graph。该 descriptor 只包含八条公开路由、namespace、option、arity、mutual-exclusion 与 symbolic owner facts，不得包含 imported callback、Context object、`open_gezhi()`、configuration/domain validator 或 business dependency。

Help、version、unknown command/option 与其他 grammar-failure path 只使用这张 inert routing graph，不 resolve、import 或调用任何 Context adapter。只有 grammar 已选择一个 valid daily command 后，bootstrap 才 resolve/import 恰好该 route 的 owning command adapter；随后该 adapter 才可进入 [ADR 0032](./0032-use-static-composition-and-context-deep-modules.md) 的 `open_gezhi()` static composition 与 owning deep-module interface。该 composition 只冻结 repository-owned static ownership 与 deep-module interface，不授权 eager import、构造或 probe 无关 Context-only business dependency；每个已选 adapter/deep module 仍只加载当前 operation 实际消费的 capability。Route ownership 仍是 repository-owned static data；不得使用 package entry-point discovery、目录扫描、dynamic registry、plugin 或 fallback adapter。

除上述对 ADR 0111/ADR 0112 的局部 replacing scope 外，[ADR 0110](./0110-run-a-decoded-argv-resource-preflight-before-typer.md) 至 [ADR 0116](./0116-return-2-with-one-fixed-stderr-line-for-raw-argv-resource-violation.md) 的 preflight-first、唯一 immutable snapshot、argv0 exclusion、关闭 completion、resource ceilings、fixed resource receipt 与 pre-PASS negative-import 边界继续有效；T02 已冻结的 typed bootstrap verdict/receipt 与 actual import/provider/validator/factory/construction exception 不被 relabel 的语义也不改变。本决定以 route-specific late import failure 和一条显式 adapter resolution seam 为代价，缩小 bootstrap failure blast radius，使 help/version/parser 与无关 Context 在 Context-only dependency 缺失时仍可使用。
