# 使用封闭的两字段 Answer error object

Knowledge v1 的非空 terminal manifest `error` 必须且只能包含必填、非 `null` string 字段 `code` 与 `stage`，并禁止任何额外字段。核心 manifest 不预留或持久化 `message`、`details`、异常类型、堆栈、绝对路径、Windows/provider 原始错误或空占位字段；人用说明由 CLI 根据稳定错误码映射生成。Codex 原始事件与已经批准保留的失败现场继续按既有合同作为受封闭清单约束的审计资产保存；除此以外的原始诊断，只有经过后续独立批准的版本化、限长与敏感信息边界后才能持久化。该选择以仅看 manifest 无法获得自然语言异常或环境细节为代价，换取确定 Schema、稳定机器接口、较低的隐私泄漏风险与可在首个 Windows 实现中机械验证的终态收据；`stage` 与 `code` 的具体枚举已经由 ADR 0059、0060 冻结。ADR 0089 已冻结本次 invocation 的 CLI `diagnostics` outer，ADR 0091 已冻结共享 item/profile，ADR 0092 已冻结 committed Answer 的 manifest-error-to-primary 静态表，ADR 0093 已冻结 no-commit outcome/result 分类与正常 JSON exit，ADR 0094、ADR 0095 与 ADR 0096 已分别冻结 no-commit blocked、failed 与 interrupted primary/context，ADR 0097 已冻结跨 outcome 静态优先级，ADR 0098 已冻结 cancellation/identity cutover，ADR 0099 已冻结 no-commit drain/cleanup 安全证明；supplemental、Human 文案和任何持久诊断资产仍单独待定，且不得扩展 ADR 0083 的 v1 顶层闭包。
