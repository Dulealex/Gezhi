# 首先交付本地 PDF 到可引用回答的纵向闭环

格致首个端到端验收闭环从用户显式提供的本地 PDF 与最小元数据开始：Literature 建立身份和来源、生成 Canonical Reading Asset、调用隔离的运行端 Codex 形成阅读结果与 Candidate Knowledge，并在异步 Candidate Review 后生成 Reviewed Handoff；Knowledge 随后幂等导入候选，并完成检索与可引用回答。自动搜索、联网获取、多来源竞争、Research Interest 管理与 Relevance 生成、Obsidian、Daily/Weekly Brief 和定时调度不属于首个闭环，它们只能在这条主干通过后作为独立上游、语义能力或输出适配器接入。
