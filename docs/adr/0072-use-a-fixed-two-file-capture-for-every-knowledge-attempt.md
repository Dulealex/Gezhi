# 为每个 Knowledge attempt 使用固定双文件捕获

[ADR 0106](./0106-run-command-owned-children-without-a-console.md) 已把 prompt stdin 冻结为专用 pipe、events stdout 冻结为专用 pipe、stderr 冻结为 `NUL`；stdin/stderr 都不是第三项 capture 或持久资产，且不得从 stderr 重建 `events.jsonl` 或 `final_message.txt`。

Knowledge v1 的每个已 launch-committed attempt 必须且只能在其 ordinal 目录保存 `events.jsonl` 与 `final_message.txt` 两个原始捕获文件；两项始终成对存在并都允许 0 bytes，`attempts=[]` 时则禁止整个 `attempts/` 树。它们表示本地 collector 对 Codex `--json` stdout 与 `--output-last-message` 通道实际取得的 bytes，而不声明 provider 一定创建过事件或 final message；CreateProcess failure、通道未建立或没有输出统一以空 bytes 表示，不增加 presence/process-created 字段。`events.jsonl` 保留可安全关闭、读取并哈希的实际捕获 bytes，包括 0-byte 捕获以及导致 `process_error` 的编码、framing、JSON 或已知 collector truncation 现场；0 bytes 只产生零条 record，本身不选择 failure class，clean EOF 下缺少末尾 LF 但最后 object 完整也不算截断。`final_message.txt` 是非零 Candidate Answer validation 的唯一模型文本来源，不得从 events、stderr 或其他副本重建。两者都不得为了通过验证而主动截断、重编码、规范化或追加换行；既有 65536-byte final text 限制只决定 validation 是否通过，不授权改写捕获文件，逐文件 capture cap 与包含边界由 ADR 0077 冻结，overflow exact-prefix retention 由 ADR 0078 冻结，witness、Job stop 与 mechanical drain 由 ADR 0079 冻结，classification/top terminal/nonretry 由 ADR 0080 冻结，正式 events 的 usage 长度门禁由 ADR 0081 冻结；外部诊断仍待后续冻结。若任一捕获无法安全关闭、读取、哈希或与另一项共同安装，就不能冻结完整 item 或 terminal manifest，只留下 staging。首版禁止持久化 stderr、argv/env、独立 session/request/thread 状态、`attempt.json`、逐 attempt prompt/schema 副本及任何其他 attempt 文件；原始 events 中不可避免的 provider ID 或结构化诊断只作为不透明本地审计窄例外，禁止提取到 manifest、CLI 展示、索引或遥测。该固定二文件接口让 `attempts` 数组唯一决定 0、2、4 或 6 个 attempt 资产路径，避免条件存在字段和旧 WSL 临时文件布局；两项捕获的精确 media identity 由 ADR 0073 统一冻结为无参数 `application/octet-stream`，语义层编码验收由 ADR 0074 冻结为严格 UTF-8 且不修复，event record framing 由 ADR 0075 冻结为 raw LF 加可选 EOF tail，逐文件 cap 与包含边界由 ADR 0077 冻结，overflow exact-prefix retention 由 ADR 0078 冻结，witness、Job stop 与 mechanical drain 由 ADR 0079 冻结，overflow 的最高优先级不可重试 `process_error` 与 `failed: codex_process_failed` synthesis 映射由 ADR 0080 冻结，正式 events usage 投影由 ADR 0081 冻结。

ADR 0076 只冻结上述 capture retention 保证的量词域为单个已提交 terminal Answer 的正式资产，并排除 writer-private spool 的瞬时物理峰值、orphan staging 与历史累计；精确 cap 与包含边界已由 ADR 0077 冻结，overflow 的 exact-prefix retention 已由 ADR 0078 冻结，witness、Job stop 与 mechanical drain 已由 ADR 0079 冻结，classification/top terminal/nonretry 已由 ADR 0080 冻结，正式 events 的 usage 长度门禁已由 ADR 0081 冻结；外部诊断仍待决定。除该 capacity overflow 窄例外外，本决策不授权主动截断或改写。
