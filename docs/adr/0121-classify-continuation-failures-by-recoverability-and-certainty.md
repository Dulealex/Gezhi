# 按可恢复性与确定性分类审核续行故障

Review Decision 后的 Handoff 与 Knowledge import 续行先经过实际消费 Data Root 的 physical gate并选择 context-specific root code；Resume 对 Registry unavailable/busy、revision conflict、Registry conflict、asset integrity 与 commit failure 使用对应 specific stage reason，specific 与 generic verdict 互斥且 specific 优先，只有 Handoff 或 `KnowledgeIntake` interface 返回的其余已批准 typed recoverable prerequisite 才分别使用 generic `handoff_blocked`/`import_blocked`。确定性的其余已批准 typed interface failure 才使用 generic `handoff_failed`/`import_failed`，unknown、untyped 或 commit-uncertain 状态一律位于正常 handled 矩阵外。本决定部分取代 [ADR 0026](./0026-continue-review-through-handoff-and-knowledge-import.md) 对 Handoff/import failure 的笼统 blocked 映射；此前已明确提交的 Decision、Handoff 或 Registry facts 不回滚，后续 invocation 必须以相同 Candidate、payload、revision 与 Handoff identity 重试。
