# Triage Labels

| MATT role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分定义，可由 agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不实施 |

所有 MATT skills 必须通过这张映射表解释标签角色。
